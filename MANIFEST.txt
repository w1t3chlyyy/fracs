Fracs — редактирование каналов в админке + ember-редизайн кабинета и админки
============================================================================

Что нового в этом архиве (поверх предыдущего):

1. АДМИНКА — редактирование обязательных каналов (вкладка «Каналы»)
   - Добавляйте/удаляйте каналы прямо в панели (@username или числовой ID -100…).
   - Кнопка «Проверить» резолвит канал через бота (getChat) и проверяет, что бот —
     админ в канале (иначе getChatMember чужих пользователей не сработает).
   - Каналы хранятся в БД: app_settings, key 'required_channels' (JSON-массив).
     Миграция НЕ нужна — таблица app_settings уже существует (используется для
     тарифов и обучения). Ключ создаётся при первом сохранении из админки.
   - Бот (checkChannelSubs, subsGateKb) и кабинет читают каналы из БД (in-memory
     кэш 60с, refresh при сохранении). Если в БД пусто — fallback на env
     REQUIRED_CHANNELS. Таким образом REQUIRED_CHANNELS теперь опционален:
     задайте через админку, либо оставьте в env как значение по умолчанию.

2. EMBER-РЕДИЗАЙН ЛИЧНОГО КАБИНЕТА
   - Shell (навигация, логин-карта, табы, секция, футер, состояния locked/paid).
   - PlansModal (модалка подписки), ResultPanel (статистика, карточки, замок),
     RecordCard (карточка организации + чипы контактов).
   - Scoped-CSS-блок .ember-cabinet в index.css: переводит светлые Tailwind-утилиты
     вложенных инструментов (AppPanel/TgTool/DemoTool/MapsTool/History/…) в тёмную
     палитру, не трогая оранжевые акценты (#F26522) и тёмные блоки.

3. АДМИНКА — ember-тема
   - Палитра панели переведена в ember через CSS-переменные (--bg #100c0a,
     --card #1e1611, --text #fbf3ea, акцент #f26522). Структура и логика без изменений.

Файлы архива (по группам):
  Каналы (бэкенд):     server/db.ts, server/bot.ts, server/adminRoutes.ts
  Каналы (админ-UI):   public/admin.html, public/admin.js
  Кабинет ember:        src/index.css, src/cabinet/Cabinet.tsx,
                        src/cabinet/PlansModal.tsx, src/cabinet/ResultPanel.tsx,
                        src/cabinet/gis/RecordCard.tsx
  Сборочные бандлы:     server.js, api/index.js (пересобраны; можно пересобрать
                        `npm run build`)

Как применить:
  1. Распакуйте архив поверх корня репозитория (с сохранением путей) — файлы
     заменят предыдущие версии.
  2. npm install && npm run build  (пересоберёт dist; server.js и api/index.js
     уже в архиве, но пересборка не повредит).
  3. Миграция БД НЕ требуется (app_settings существует; required_channels —
     новый ключ, создаётся при первом сохранении из админки).
  4. Зайдите в админ-панель (/admin.html через бота) → вкладка «Каналы» →
     добавьте каналы, нажмите «Проверить» (убедитесь, что бот админ), «Сохранить».
