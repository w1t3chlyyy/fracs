Fracs — все изменения сессии: редизайн лендинга + админка + подписка/триалы
Базовый комитет: 13fec96 (Create security.ts)

Как применить в вашем репозитории:
  1. Распакуйте архив поверх корня репозитория (с сохранением путей).
  2. Удалите файлы из DELETED.txt — это устаревшие артефакты сборки (старые server.ts и public/assets/aistudio/*).
  3. npm install && npm run build — пересоберёт бандлы server.js и api/index.js, если ваш CI этого требует.
