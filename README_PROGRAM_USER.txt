Fracs Parser
============
1. Установите Google Chrome (или Microsoft Edge на Windows), если ещё не установлен.
2. Запустите FracsParser (FracsParser.exe на Windows). Откроется окно консоли и страница программы в браузере.
3. Один раз вставьте ключ лицензии из личного кабинета Fracs (Карты 2ГИС → Программа).
4. Соберите ссылки, настройте фильтры и нажмите «Запустить». Результат можно выгрузить в HTML, CSV, XLSX, JSON.

Не закрывайте окно консоли, пока идёт парсинг: закрытие окна останавливает программу.
Программа работает, пока активна подписка; без интернета — до 3 суток по последней проверке.
Windows: при предупреждении SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».
macOS: правый клик по FracsParser → «Открыть».
