# Личный кабинет Fracs: что добавлено

Лендинг остался как был. Добавлены: страница `/app` (кабинет), Express-бэкенд и вход через Telegram-бота.

## Запуск

```bash
npm install          # новых зависимостей нет, bun.lock остаётся валидным
cp .env.example .env # для первого запуска можно ничего не заполнять
npm run dev          # http://localhost:3000
```

Без `TELEGRAM_BOT_TOKEN` в dev-режиме на странице входа появится ссылка «Войти без бота». Оплата по умолчанию тестовая: подписка выдаётся сразу.

Продакшен: `npm run build && npm start` (нужны `SESSION_SECRET` и `NODE_ENV=production`, `start` ставит его сам).

## Как это работает

| Шаг | Что происходит |
|---|---|
| Вход | Сайт создаёт одноразовый токен → ссылка `t.me/<бот>?start=<токен>` → бот подтверждает токен → сайт получает подписанную cookie-сессию |
| Карты | Ниша (свободный текст) + город из списка (~820 городов РФ, поиск понимает раскладку «rfpfym», опечатки и сокращения) |
| Telegram | Фраза «кому что нужно» + период 1–3 дня |
| Без подписки | Видны цифры и 3 замаскированные строки. Маскирование делается на сервере, полные данные не уходят в браузер |
| С подпиской | Полные строки, «показать ещё», выгрузка CSV |
| Оплата | ЮKassa (редирект + вебхук с перепроверкой статуса через API) или тестовый режим |

Повторный запрос с теми же параметрами за 24 часа возвращает прежний результат и не тратит дневной лимит (`DAILY_SEARCH_LIMIT`).

## Провайдеры данных (`server/providers.ts`)

- `MAPS_PROVIDER=mock` — цифры генерируются случайно, но детерминированно от «ниша + город». В интерфейсе стоит плашка «Демо-режим».
- `MAPS_PROVIDER=2gis` — реальный поиск через Places API 2ГИС (`GIS_API_KEY`), берёт до 500 карточек и оставляет те, где нет сайта. Написан по описанию из README saleshustlify, исходники репозитория мне были недоступны — сверьте поля ответа с вашей подпиской.
- `TG_PROVIDER=http` — ждёт от вашего сервиса (репозиторий `lead`, он на Python/Telethon и в Node не переносится) эндпоинт `POST {TG_PARSER_URL}/search` с телом `{phrase, days}` и ответом `{rows: [{id, username, name, chat, text, date, link}]}`.

## Что поменять под себя

- Цены тарифов — `PLANS` в `server/config.ts` (сейчас 4 900 / 12 900 ₽, это заглушки).
- Список городов — `server/cityData.ts` (добавьте названия в нужный регион).
- Хранилище — `server/db.ts` пишет JSON-файл `data/db.json`. Для нескольких инстансов замените на Postgres/Supabase, остальной код трогать не нужно.
- В навигацию лендинга кабинет не вшит, чтобы не переписывать `App.tsx`: пока он открывается плавающей кнопкой справа внизу. Чтобы добавить пункт в меню, вставьте `<a href="/app">Кабинет</a>` рядом с остальными ссылками в `App.tsx`.

## Перед приёмом денег

- Если оставить `mock`-провайдеры, клиент заплатит за выдуманные «компании» и «людей». На боевом сайте включайте `2gis` и `http`.
- Для чеков по 54-ФЗ в запрос ЮKassa нужно добавить `receipt` (email/телефон покупателя): в `server/payments.ts` его пока нет.
- Лендинг заявляет «0% риска блокировок», «открываемость 85%», «конверсия 24,6%» и кейсы с цифрами. Проверьте, что это подтверждено, иначе это риск по закону о рекламе.
