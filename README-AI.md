(там, где лежит папка `desktop/` и `server/`) — все файлы лягут на свои места сами:

## Порядок установки

```bash
cd <корень-репозитория-сайта>
unzip -o fracs-fixes-v2.zip        # файлы лягут: server/*.ts, desktop/parser_2gis/…
python3 apply_fixes.py             # точечные патчи + проверка полных файлов
```

`apply_fixes.py` в конце проверяет все 5 полных файлов и печатает OK/FAIL по каждому.

`postcard-sample.png` — пример новой открытки (1200×675, по макету заказчика),
`site-review-sample.mp4` — пример видеообзора, который открывает QR.


## Что сделано

### 1. AI действительно работает, все провайдеры
12 провайдеров: **Fracs AI** (встроенный, OpenRouter+Bazaar, только PRO), Z.ai, OpenAI,
Anthropic, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI, Ollama (локально,
без ключа) и **Custom** — любой OpenAI-совместимый endpoint (vLLM, LM Studio, прокси).
Провайдер выбирается в списке; для Custom появляется поле Base URL.

### 2. Модели — автоматически
Новый эндпоинт `GET /api/ai/models?provider=…&api_key=…&base_url=…` тянет список моделей
прямо из API провайдера. У OpenRouter каталог открыт (Bazaar), у остальных — по ключу;
если API недоступен, показывается встроенный fallback-список. Кнопка «↻» обновляет список,
чекбокс «ввести модель вручную» — на случай кастомной модели. Ввод ключа тоже
автоматически перезагружает список (некоторые API отдают модели только со своим ключом).

### 3. Файлы: справа — то, что отдаёт агент; свои — прямо в чате
- Скрепка в чате открывает выбор файлов (можно несколько). Файлы уходят на
  `POST /api/ai/upload` (привязаны к сессии в localStorage), показываются чипами над
  полем ввода и в правой панели в секции «Мои файлы (в чате)».
- Текстовые файлы (txt/md/html/css/js/json/csv/py/…) попадают в промт как контекст,
  картинки (png/jpg/webp/gif ≤5 МБ) — как vision-сообщение для провайдеров с поддержкой
  изображений; если провайдер без vision, агент пишет об этом в чат.
- Правая панель теперь с двумя секциями: «Файлы агента» (site.zip + postcard.png после
  одобрения) и «Мои файлы (в чате)».
- Новое: если отправить сообщение, когда превью уже есть, агент получает предыдущую
  версию сайта как контекст — правки делаются поверх, а не с нуля.

### 4. Один общий промт против нейрослопа + ExtraПромт
`_SYSTEM_PROMPT` в `ai_agent.py` единый для ЛЮБОЙ подключённой нейросети: техправила
(тёмная тема, #F26522, всё inline, адаптив) + блок «АНТИ-НЕЙРОСЛОП» — запрет
канцелярита («инновационный», «индивидуальный подход», «надёжный партнёр»), живой ритм
предложений, конкретика из задания, заметные маркеры `[ЦЕНА УТОЧНЯЕТСЯ]` для данных,
которых нет. ExtraПромт пользователя (поле на панели) добавляется в тот же system-промт
с пометкой «имеют приоритет».

### 5. Fracs AI (OpenRouter + Bazaar) — только PRO
- Провайдер «Fracs AI» работает на ключе оператора: переменная окружения
  `FRACS_AI_API_KEY` (или `OPENROUTER_API_KEY`). Пользователю ключ вводить не нужно.
- Модели — каталог OpenRouter, кураторский список Bazaar: сначала `:free`-модели,
  затем популярные (GPT/Claude/Gemini/Llama/DeepSeek/Qwen/Mistral/Grok), до 120 позиций.
- Гейт: `fracs_ai_allowed()` проверяет активную лицензию Fracs. Доступ разрешён, если
  тариф PRO или Бизнес — по `features` ('pro'/'fracs_ai'/'business') или имени тарифа.
  Не PRO → провайдер в списке задизейблен, `/api/ai/start` и `/api/ai/test` возвращают
  403 с `pro_required`, UI показывает «Оформите PRO».
- Если ключ на сервере не задан, UI честно пишет «Fracs AI ещё не настроен на этой сборке».

### 6. Новая открытка с QR
Вместо «текст + QR на чёрном фоне» — макет 1080×1528: тёмный вертикальный градиент,
оранжевое свечение из угла, халфтон-сетка точек, полосы-акценты сверху/снизу, вордмарк
FRACS + бейдж AI-AGENT, QR на белой скруглённой карточке с мягкой тенью и оранжевыми
уголками-скобками (как видоискатель камеры), блок «ЗАДАНИЕ АГЕНТУ» с цитатой-промтом,
моноширинный URL превью и подвал «Собрано в Fracs Parser · дата».

## API-эндпоинты (новые/изменённые)
```
GET    /api/ai/providers                  — список провайдеров (+pro_only/allowed/configured)
GET    /api/ai/models                     — автосписок моделей провайдера
POST   /api/ai/upload                     — multipart(session_id, files[]) — скрепка
GET    /api/ai/uploads/<session_id>       — вложения сессии
DELETE /api/ai/uploads/<session_id>       — очистить вложения
POST   /api/ai/start                      — + session_id, prev_job, base_url, temperature, max_tokens
GET    /api/ai/status/<job_id>            — + uploads, model, provider
остальные (/preview, /approve, /download, /test) — как раньше
```

## Как проверить без нейросети
`python3 scripts/ai_e2e_test.py` — поднимает мок-программу на http://127.0.0.1:8667/
и фейковый OpenAI-совместимый LLM на 127.0.0.1:8670. В программе: вкладка AI →
провайдер Custom → Base URL `http://127.0.0.1:8670/v1` → любой ключ → скрепка/промт.
Проверено: провайдеры, автозагрузка моделей (477 моделей с реального OpenRouter),
скрепка, генерация, одобрение, ZIP, открытка, гейт PRO.

## Совместимость
`server.py` менять не нужно — маршруты регистрируются через `ai_agent.register()`,
гейт лицензии для `/api/ai/*` остаётся публичным (свои ключи), а Fracs AI проверяет
подписку внутри. Старые вызовы (`{prompt, api_key, model, provider, extra}`) работают
без изменений.

## Обновление 2 (фиксы по скриншотам + избранное + «Собрать макет»)

1. **Дубли логов в чате AI-Агента — исправлено.** Причина: каждый опрос статуса
   добавлял в чат ВСЕ строки лога заново, а сообщение «Превью готово» вставлялось
   на каждом опросе. Теперь в чат пишутся только новые строки (счётчик `seenLogs`),
   превью и «Готово» показываются один раз (`previewShown`/`doneShown`).

2. **«Создать фразы (FracsAI)» — работает, а не заглушка.** Новый эндпоинт
   `POST /api/ai/phrases`: берёт провайдера/ключ/модель из настроек AI-Агента
   (Fracs AI — только PRO, гейт тот же), просит LLM сделать до 20 живых поисковых
   фраз (с опечатками и разговорными формулировками), вычищает нумерацию/буллеты
   и дубли. Фразы показываются чипами: «+» добавляет фразу в поле слева,
   «Добавить все» — весь список, дальше обычный «Запустить» Telegram-поиска.
   Если ключа нет — понятное сообщение, а не молчание.

3. **Избранное.** Звёздочка в шапке каждой карточки бизнеса, состояние хранится
   в localStorage (`fracs_favs`, ключ — id карточки 2ГИС). Кнопка «Избранное»
   в топбаре включает фильтр «только избранные»; если снять звезду в режиме
   фильтра, карточка сразу скрывается. Пустое избранное — понятная заглушка.

4. **Кнопка «Собрать макет» в карточке бизнеса.** Собирает структурированный
   промт из данных карточки (название, рубрики, адрес, телефон/WhatsApp/
   Telegram/Instagram/сайт/e-mail, рейтинг и отзывы, владелец), переключает на
   вкладку AI-Агент и сразу запускает генерацию. Ключа нет? Промт вставится в
   поле чата с подсказкой вставить ключ. Модель/провайдер — те же, что выбраны
   на вкладке AI; работает и через Fracs AI на PRO.

## Обновление 3 — уровень дизайна (как fracs.cc), индивидуальный под каждый бизнес

По 21st.dev и motionsites.ai: **motionsites.ai платный** (код только на подписке
«Unlimited», бесплатно — превью); **21st.dev — код открыт, но компоненты
React+Tailwind**, в однофайловый HTML без сборки напрямую не вставить. Поэтому
уровень реализован бесплатно и надёжно — внутри самого приложения:

1. **DESIGN_LIB — библиотека премиум-блоков** (в ai_agent.py, вшита в системный
   промт): плавающая стеклянная навигация-пилюля, герой с градиентным пятном и
   halftone-точками + двухстрочный H1 с курсивным акцентом, бегущая строка,
   сетка услуг с hover-подъёмом, полоса цифр, отзывы, FAQ-аккордеон на
   <details>, CTA-баннер, футер, анимация появления на IntersectionObserver со
   стаггером, запрет на «дешёвый» дизайн (плоский фон, border-radius:4px, нет
   hover).

2. **Индивидуальный дизайн обязателен**: модель сначала выбирает направление под
   рубрику (характер, палитра, пара шрифтов из Google Fonts) и вшивает в HTML
   комментарий `<!-- design brief: ... -->`. Примеры: автосервис — графит +
   сигнал-красный, Unbounded + Inter; кофейня — крем + терракота, Fraunces +
   Manrope; стоматология — светлый + бирюзово-синий, Sora; барбершоп — чёрный +
   латунь, Bebas Neue. Одна палитра на все бизнесы больше НЕ задана (раньше
   промт жёстко требовал тёмный + оранжевый у всех).

3. **max_tokens для генерации поднят 4096 → 16384** — страница уровня
   fracs.cc в 4К токенов не помещается.

Фейковая модель в тестах выдаёт страницу, собранную по этим же рецептам —
превью «Автосервис «Мотор»: preview-motor-premium-hero/mid/bottom.png,
HTML: preview-motor-premium.html.

## Обновление 4 — типографика и стилевые промты «точная реконструкция»

Проблема: вёрстка выглядела как нейрослоп — смешение Unbounded+Georgia-курсива,

### Источники бесплатных промтов (проверено через headless Chrome)

  fernhollow_flower_valley.txt (13.2 КБ).

  без аккаунта промт не отдаётся; код компонентов (React+Tailwind) открыт, но в
  однофайловый HTML не переносится напрямую. Пропущено.

### Что изменено в ai_agent.py
1. **TYPO_RULES** — жёсткие типографические правила вместо свободных «рецептов
   блоков»: максимум 2 семейства шрифтов, дисплейный только для H1/цифр/логотипа,

   подписи max-width 36ch, текст max-width 62ch, маркиза 12px uppercase ls .12em
   без жирных акцентов, в статах число отдельно от слова, кнопки 48px, отступы
   секций 96-128px.
2. **STYLE_PROMPTS** — 6 стилевых рецептов в формате «точной реконструкции»
   (как у motionsites), по одному на тип бизнеса: «Цех» (авто), «Обжарка» (кофе),
   «Доверие» (медицина), «Латунь» (барбершоп/красота), «Бетон» (стройка/мебель),
   «Люкс» (нейтральный). В промт генерации попадает ОДИН, выбранный функцией
   _pick_style() по рубрике карточки. Палитры и шрифты заданы в рецепте.
3. **max_tokens** по-прежнему 16384.

## ОБНОВЛЕНИЕ 8 — Автозагрузка .env (почему «нет ключа FRACS_AI_API_KEY»)
════════════════════════════════════════════════════════════════════

Причина ошибки на скрине: программа не видела OPENROUTER_API_KEY — файл .env
раньше никто не загружал (env-ключи в коде читаются из окружения процесса).
В ai_agent.py добавлен _load_dotenv(): при старте ключи читаются из .env.

### Где лежит .env (любое из мест, приоритет: программа → exe → CWD)
- dev-сборка: desktop/.env (папка, в которой лежит parser_2gis);
- PyInstaller-сборка: .env РЯДОМ С .exe;
- либо текущая рабочая папка.
Переменные, заданные в системе, приоритетнее .env (не перезаписываются).

FRACS_OWNER_MODE=1                # Ultra до 2099
FRACS_AI_API_KEY НЕ нужен — опциональная заготовка под свой сервер.

### Про «Bazaar API»
Bazaar — НЕ отдельный сервис и НЕ отдельный ключ. Это название каталога
моделей Fracs AI (ai_agent.py, «Каталог Fracs AI (Bazaar)»): модели
автоматически тянутся через OpenRouter /models с ТЕМ ЖЕ ключом
OPENROUTER_API_KEY — бесплатные первыми. Никакой BAZAAR_API_KEY добавлять
не нужно. Провайдер Fracs AI после этого запускается как на скрине
(модель baidu/ernie-…:free), но уже без ошибки.

ошибка «нет ключа» исчезла.
