# Fracs: демо на сайте + программа для ПК

Бесплатно на сайте — **демо** парсера 2ГИС (данные сгенерированы в браузере, никаких запросов к 2ГИС). После оплаты в кабинете открывается **программа Fracs Parser**: скачивание, ключ лицензии, реальный парсинг на компьютере пользователя.

## Что в архиве

| Путь | Что это |
|---|---|
| `desktop/` | Программа: весь парсер из `pars-main.zip` + Fracs-оформление, проверка лицензии, `fracs_parser.py` (запуск), `fracs_parser.spec` (сборка) |
| `.github/workflows/build-app.yml` | Сборка под Windows, macOS (M1+ и Intel), Linux и публикация в Release |
| `server/appRoutes.ts` | Ключ лицензии, защищённое скачивание, проверка подписки для программы |
| `server/app.ts` | Изменён: подключён `/api/app` |
| `src/cabinet/gis/` | Демо парсера, раздел «Программа» |
| `src/cabinet/Cabinet.tsx`, `PlansModal.tsx` | Вкладка «Карты 2ГИС» = Программа / Демо; тексты тарифа под программу |
| `public/2gis/generator.json` | Справочники для генератора ссылок (демо) |
| `.env.example`, `.vercelignore` | Новые переменные; `desktop/` не попадает в деплой Vercel |

## Если вы уже залили прошлый архив — удалите

`parser-service/` (серверный Docker-парсер больше не нужен), `server/gis.ts`, `server/gisConfig.ts`, `server/gisDb.ts`, `server/gisRoutes.ts`, `src/cabinet/gis/GisTool.tsx`, `src/cabinet/gis/GisHistory.tsx`. Таблица `gis_jobs` в Supabase и файл `supabase/gis_jobs.sql` не нужны.

## Запуск

1. **Репозиторий GitHub → Settings → Secrets and variables → Actions → Variables**: `FRACS_SITE_URL` = адрес сайта, например `https://fracs.ru` (его вшивает в программу сборка).
2. **Actions → Build Fracs Parser → Run workflow**, версия `1.0.0`. Через ~10 минут в Releases появятся `FracsParser-windows.zip`, `-macos-arm64.zip`, `-macos-x64.zip`, `-linux.zip`. Репозиторий лучше держать приватным.
3. **Vercel → Environment Variables**: `APP_RELEASE_REPO=владелец/репо`, `APP_RELEASE_TOKEN=<fine-grained токен, Contents: Read-only>`. Redeploy.
4. Готово: оплатили подписку → кабинет → «Карты 2ГИС» → «Программа» → скачать + ключ.

Обновление программы: новый запуск workflow с новой версией; кабинет всегда отдаёт последний релиз.

## Как работает лицензия

Ключ `fracs.<id>.<подпись>` показывается подписчику в кабинете и подписан `SESSION_SECRET` (в базе не хранится). Программа спрашивает `POST /api/app/verify`: подписка активна — работает, нет — просит продлить. Без интернета работает до 72 часов по последней успешной проверке. Без ключа закрыты и дашборд, и консольный режим.

Это защита от случайного распространения, а не от взлома: код программы на Python, и решительный человек может убрать проверку. Если ключ утёк, его можно отозвать только сменой `SESSION_SECRET` (это отзовёт ключи всех пользователей и выкинет их из кабинета).

## Что изменено в парсере

- Исправлен баг архива: `chrome/remote.py` вызывал отсутствующие `output_tail()` и `log_path`, из-за чего при сбое запуска браузера вместо понятной ошибки падал `AttributeError`.
- Если нет Chrome, используется Microsoft Edge (Windows/macOS), Chromium (Linux).
- Дашборд: оформление Fracs (оранжевый, Jost/Montserrat), русский по умолчанию, экран активации лицензии.
- Остальное (фильтры, районы, Яндекс Карты, XLSX по листам, история, объединение) — как в оригинале. Лицензия LGPLv3 сохранена (`desktop/LICENSE`).

## Проверено и не проверено

Проверено: лицензионная логика (нет ключа / неверный / истёкший / активный / офлайн-режим 72 ч) на тестовом сервере; сборка PyInstaller под Linux и запуск собранной программы с активацией; демо-генератор; TypeScript серверной и клиентской частей.
**Не проверено:** сборка под Windows и macOS (у меня нет этих систем — их соберёт GitHub Actions; первый запуск проверьте), реальный парсинг 2ГИС (из моей среды сайт недоступен) и скачивание из приватного Release с вашим токеном.
