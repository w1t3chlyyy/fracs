## AI-Агент — теперь с бэкендом

Программный AI-Агент получил реальный бэкенд (`desktop/parser_2gis/web/ai_agent.py`):

1. Пользователь вставляет свой API-ключ (Z.ai / OpenAI / Anthropic) и пишет промт.
2. `POST /api/ai/start` запускает фоновую задачу: агент обращается к LLM и
   генерирует одностраничный сайт.
3. `GET /api/ai/preview/<job_id>` отдаёт готовый HTML на localhost — пользователь
   видит превью.
4. `POST /api/ai/approve/<job_id>` — после одобрения агент собирает:
   - **ZIP** (`site.zip`) с `index.html` и `README.md` — готов выложить на любой
     статический хостинг;
   - **PNG-открытку** (`postcard.png`, 720×1020) с QR-кодом, ведущим на превью,
     и краткой выжимкой промта.
5. `GET /api/ai/download/<job_id>?type=zip|png` отдаёт файлы на скачивание.
6. `POST /api/ai/test` пингует связку «ключ → модель → нейросеть».

Все маршруты AI-Агента (`/api/ai/*`) и `/api/plans` публичные — они не требуют
лицензии Fracs, потому что AI работает на ключе пользователя, а тарифы нужны
до оплаты.

## Как запустить программу локально

```bash
cd desktop
pip install -r requirements.txt
python -m parser_2gis --web      # откроет http://127.0.0.1:8666/
```

Flask должен быть установлен (`pip install Flask qrcode Pillow requests`).

## Как проверить AI-Агент без программы

```bash
python3 /home/z/my-project/scripts/prog_mock_server_v2.py   # http://127.0.0.1:8667/
```

Мок-сервер отдаёт редизайн index.html и стабы для всех API: license=ok pro,
plans=3 тарифа, generator=реальные данные, training=2 урока, tg/search=2 строки,
ai/start+status+approve=рабочий флоу с превью и скачиванием ZIP+PNG.
