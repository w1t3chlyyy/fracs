# Патч Fracs: как применить
Структура папок повторяет репозиторий — скопируйте поверх, подтвердив замену файлов.
Файлы `_preview_*` — только для просмотра, в репозиторий не нужны.

После копирования:
1. Supabase → SQL Editor: выполнить `supabase/ai_usage.sql` (учёт расходов Fracs AI).
2. `.env` на сервере: см. новые строки в `.env.example` (лимиты AI_*, FRACS_DEMO_BASE_URL).
3. `pip install -r desktop/requirements.txt` (добавлен telethon); для mp4 — по желанию playwright + ffmpeg.
4. Тариф Ultra: если планы переопределены в БД, выполните resetPlans в админ-боте или добавьте
   возможность `tg_broadcast` вручную.
5. `npm run build` (проверка типов сервера и кабинета).
